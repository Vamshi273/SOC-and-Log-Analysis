# SOC and Log Analysis Toolkit

A comprehensive cybersecurity project featuring practical
Security Operations Center (SOC) tools, log analysis,
threat detection, incident investigation, and security automation.

## Modules

1. Windows Event Log Analysis
2. Linux Authentication Log Analysis
3. SSH Brute Force Detection
4. Apache Access Log Analysis
5. Failed Login Detection
6. Privilege Escalation Detection
7. PowerShell Threat Detection
8. Suspicious Process Detection
9. IP Threat Intelligence
10. IOC Extractor
11. File Integrity Monitoring
12. Security Incident Reporter
13. SIEM Log Correlation
14. DNS Threat Analysis
15. Security Dashboard

## Technologies

- Python
- Windows Event Logs
- Linux Logs
- Pandas
